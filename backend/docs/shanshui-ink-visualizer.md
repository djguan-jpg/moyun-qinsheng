# 山水設色・聲染

依 2026-08-26 使用者最新指示改採暈墨；此指示取代先前禁止墨暈的限制。

## 設計

- 不改三張原圖，不將效果烘焙成圖片；HTML 的 img 與透明 Canvas 分離。
- 月色：花青、淡墨為主，淡赭石為輔；避開左上月亮。
- 深色：石青、石綠為主，少量淡赭提色；暈染留在中央空間。
- 山水：花青與石綠交疊，赭石僅作小面積積色；不蓋住前景山形。
- 多層不規則輪廓、淡邊與積色；手機複驗後移除顆粒，避免深色底圖出現格點感。
- 不用方塊、航線、加號或點陣。
- 配色為螢幕上的設計近似，不宣稱是傳統實物顏料的標準色值。

## 音訊與效能

- 波形 RMS 決定濃淡；低、中、高頻分別控制色層擴張。
- 暈染進度來自音訊能量積分；沒有與音訊無關的時鐘動畫。
- 暫停、結束、靜音與無聲時透明；背景分頁停止繪製。
- 每張播放作品只建立四張 256px 暈染紋理，每幀最多四次合成，DPR 上限 2。
- 減少動態偏好會取消色團位移與慢速擴散。
- Browser skill 驗證實際 390px 手機版；不可只憑靜態截图判定播放效果。
