# 山水設色・聲染

依 2026-08-26 使用者指示改採暈墨，後續明確要求隨機移動而非固定中心。
參考：[Kylie Wang — Ink Drop Effect ｜噴墨效果練習](https://youtube.com/watch?v=aGLa22GsTE8)。
已用 Browser 實播並查看不同時間影格，參考不規則墨邊、濃淡與分岔，不複製影片素材、人物或文字。

## 設計

- 不改三張原圖，不將效果烘焙成圖片；HTML 的 img 與透明 Canvas 分離。
- 月色：花青、淡墨為主，淡赭石為輔；避開左上月亮。
- 深色：石青、石綠為主，少量淡赭提色；墨流橫跨大部分畫面，不再限制於中央。
- 山水：花青與石綠交疊，赭石僅作小面積積色；透明尾跡讓山形保持可見。
- 多層不規則輪廓、淡邊與積色；手機複驗後移除顆粒，避免深色底圖出現格點感。
- 不用方塊、航線、加號或點陣。
- 配色為螢幕上的設計近似，不宣稱是傳統實物顏料的標準色值。

## 音訊與效能

- 波形 RMS 與播放器音量決定濃淡；低、中、高頻控制三股墨流的速度與擴張。
- 每次播放各自建立隨機起點與曲線路徑，拒絕近距離目的地；到達後續接新路徑。
- 墨流真正改變 x/y 座標，移動後留下逐漸擴散、旋轉及淡出的透明墨絲。
- 進度只使用正在播放的音訊時間差及能量；沒有與音訊無關的時鐘動畫。
- 暫停、結束、靜音與無聲時透明；背景分頁停止繪製。
- 每張播放作品延遲建立八張 256px 紋理；尾跡片段上限 96，DPR 上限 2。
- 減少動態偏好會取消空間位移與旋轉。
- Browser skill 驗證實際 390px 手機版；不可只憑靜態截图判定播放效果。
